# 🔁 Materiais aprimorados

Materiais de estudo (anotações no Notion, PDFs, EPUBs, apostilas) aprimorados pela skill: mantêm a proposta do original, com correções, o que faltava e explicações mais claras, para estudar, revisar e pesquisar.

Cada material fica numa pasta própria (`materiais-aprimorados/<nome-do-material>/`) e pode ser lido aqui no GitHub, no [site](../site/) com busca ou baixado como EPUB. Do material original são usados só a estrutura, os tópicos e os objetivos; o original não é publicado.

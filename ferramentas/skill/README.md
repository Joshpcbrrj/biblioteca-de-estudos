# Arquivos auxiliares da skill `revisar-curso-biblioteca`

A skill (SKILL.md, salva na conta do usuário) fica enxuta e aponta para estes
arquivos, que são lidos só na etapa em que fazem falta. `SKILL.md` aqui é uma
cópia de referência da versão atual.

| Arquivo | Conteúdo |
| --- | --- |
| `DIDATICA_VISUAL.md` | Fase 4 completa: auditoria visual, didática, kit, design system v3, cheat sheet, regras de e-reader para SVG |
| `NOTION.md` | notas técnicas da API do Notion (troca de imagens, erros conhecidos) |
| `PUBLICACAO.md` | Fases 6 e 7: exportação, estrutura do repositório, conversão, e-reader, publicação, sincronização e resumo final |
| `CAPA.md` | direção de arte, processo e checklist da capa |

Scripts usados pela skill (em `ferramentas/`): `auditar_curso.py`,
`progresso.py`, `raw_urls.py`, `gerar_epub_local.py`, `notion2md.py`,
`verificar_epub.js` e o kit `svg/`.

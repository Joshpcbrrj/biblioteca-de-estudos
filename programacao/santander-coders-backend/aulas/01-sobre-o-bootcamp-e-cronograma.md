# Sobre o bootcamp e cronograma

> 🗺️ **Nesta página:** como funcionou o programa Santander Coders 2023, as fases da seleção com as datas, os critérios e o conteúdo do curso online que este material resume.

## Onde começamos

Este material nasceu da preparação para o **Santander Coders 2023**, programa de bolsas de estudo em tecnologia do Santander, com o curso aplicado pela **Ada Tech**. Antes do bootcamp, cada inscrito fazia um curso online curto; este livro reúne e amplia o conteúdo desse curso na trilha **Web Back-End**.

## Objetivo do programa

- Até **50 mil** inscritos selecionados recebiam bolsa para o curso online.
- Os **300** com melhor desempenho seguiam para o bootcamp completo. Havia trilhas como Web Front-End, Web Back-End, Data Science e Engenharia de Dados.
- Depois do bootcamp, os participantes podiam ser convidados pela Universia para processos seletivos de empresas parceiras.

> ⚠️ **Ajuste:** a anotação original dizia que os 300 receberiam bolsa "em Front-end, Data Science e engenharia de dados", sem citar a trilha deste curso, que é a de Web Back-End.

## Etapas

1. Inscrição e teste de lógica: seleção para as bolsas do curso online.
2. Curso online, novo teste de lógica, dinâmica em grupo e Coding Tank.
3. Divulgação dos 300 selecionados e início do bootcamp.

## Critérios

**Diversidade**: no mínimo 30% de mulheres e 40% de pessoas pretas e pardas entre os selecionados.<br />**Desempate**: primeiro o número de acertos no teste; depois, quem concluiu o curso mais rápido.

## Conteúdo do curso online

### Parte 1: curso online (bolsistas)

| Módulo | Carga |
| --- | --- |
| Git e versionamento | 1 h |
| Introdução a algoritmos | 1,5 h |
| Redes | 2 h |
| Java | 2 h |
| Programação orientada a objetos | 3 h |
| Banco de dados | 1 h |

Cada módulo virou uma seção deste material. As páginas acrescentadas para completar a proposta do curso (HTTP, coleções, exceções e consultas SQL) levam no título "(Adicionado pelo aluno para melhorar o estudo)".

### Parte 2: bootcamp (300 selecionados)

- Lógica de Programação I
- Programação Orientada a Objetos I e II
- Técnicas de Programação I
- Programação Web II
- Testes Automatizados I

> ➡️ **Próximo passo:** começar pelo primeiro módulo, Git e versionamento.

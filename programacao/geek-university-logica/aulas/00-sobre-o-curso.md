# Sobre o curso

> **🗺️ Sobre o curso:** a base de toda programação, antes de qualquer linguagem: raciocínio lógico, algoritmos, pseudocódigo, fluxogramas, variáveis, tipos, operadores e entrada e saída. Os exemplos aparecem em pseudocódigo e nas três linguagens do curso: **Python**, **Java** e **C**.

> **Como estudar:** siga as seções na ordem. Cada aula começa com o quadro "Nesta aula" e termina com um **📌 Resumo**; para revisar, leia só os resumos. Teste os exemplos no computador e faça os exercícios antes de abrir as respostas (**Ver resposta**).

> **🔖 Legenda dos quadros:** 🗺️ visão geral da aula · ✨ página nova, criada para cobrir um tópico que faltava · 💡 dica · ⚠️ cuidado · ✅ boa prática · 📌 resumo para revisão.

## Seções

| Seção | O que cobre |
| --- | --- |
| 1. Preparando o ambiente | Instalar e testar Java, C e Python no Windows |
| 2. Introdução à lógica | O que são lógica, sequência lógica, instrução, algoritmo e programa, e como se encaixam |
| 3. Desvendando algoritmos | Pseudocódigo, fluxograma, regras de escrita e as fases entrada, processamento e saída |
| 4. Constantes, variáveis e tipos | Onde o programa guarda valores, como nomeá-los e que tipo cada um tem |
| 5. Operadores, entrada e saída | Expressões aritméticas, relacionais e lógicas; ler e mostrar dados em Python, Java e C |
| 6. Prática | Exercícios para juntar tudo, do enunciado ao programa |

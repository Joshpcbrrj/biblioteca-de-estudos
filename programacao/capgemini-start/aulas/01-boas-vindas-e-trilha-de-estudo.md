# Boas-vindas e trilha de estudo

> 🗺️ **Sobre o programa:** o Start by Capgemini forma desenvolvedores do zero: começa pela lógica de programação, passa por toda a base da web (HTML, CSS, JavaScript), chega ao front-end com **Angular** e termina no back-end com **Java** e **Spring Boot**. Este caderno reúne as anotações de cada módulo, revisadas para servir de material de estudo e de revisão.

## Trilha de estudo sugerida

| Etapa | Módulos | Ao final você consegue… |
| --- | --- | --- |
| 1. Lógica | 0, 1, 2, 3 | pensar em algoritmos, usar variáveis, decisões, laços, vetores e funções, e versionar código com Git |
| 2. Web | HTML 1, HTML 2, HTML 3, HTML avançado | entender como a web funciona e montar páginas semânticas e acessíveis |
| 3. Estilo | CSS 1, CSS avançado | estilizar e diagramar com Flexbox, Grid e media queries |
| 4. Interatividade | JavaScript | organizar código em classes e módulos, manipular o DOM, tratar eventos e consumir dados com `fetch` |
| 5. Front-end | Angular, APIs com Angular | criar uma aplicação com componentes, rotas, formulários e CRUD |
| 6. Back-end | Java 1, Java 2 | programar em Java orientado a objetos, criar uma API REST com Spring Boot e ligá-la ao Angular |

## Como usar este material

- **Para estudar:** siga os módulos na ordem da trilha. Cada aula segue o mesmo roteiro: 🗺️ **Nesta aula** → **De onde paramos** (ligação com o que você já viu) → conteúdo → 🧠 **Revisão rápida** → ➡️ **Próximo passo** → 📌 **Resumo**.
- **Para revisar:** leia os resumos e responda às perguntas da revisão rápida antes de abrir a resposta (▸). Se errar, volte à seção correspondente.
- **Legenda dos quadros:**
  - 🗺️ visão geral do módulo ou da aula;
  - 💡 dica ou analogia;
  - ⚠️ cuidado: erro comum ou algo que mudou nas versões atuais;
  - ➡️ o que vem a seguir.
- **Pratique:** digite os exemplos em vez de copiar, e mude valores para ver o que acontece.

# Sobre o curso

> 🎯 Programa de formação **full stack** da Capgemini: lógica de programação → web (HTML, CSS, JavaScript) → front-end com Angular → back-end com Java e Spring Boot. Comece pela página de boas-vindas, que traz a trilha sugerida e a legenda dos quadros.

## Seções

| Etapa | O que cobre |
| --- | --- |
| 1. Lógica de programação | Algoritmos, Portugol, estruturas de dados, funções, SQL, POO, os primeiros programas em Java e versionamento com Git e GitHub |
| 2. Web e HTML | Como a web funciona, hospedagem e containers, HTML semântico, SEO, acessibilidade e segurança |
| 3. CSS | Seletores, cascata, modelo de caixa, Flexbox, Grid, responsividade, Sass e animações |
| 4. JavaScript | A linguagem do navegador: sintaxe, funções, classes e módulos (ES6), DOM, eventos e jQuery |
| 5. Front-end com Angular | TypeScript, componentes, rotas, services, formulários e consumo de APIs REST |
| 6. Back-end com Java | Fundamentos da linguagem, orientação a objetos, coleções, uma API REST com Spring Boot e o projeto full-stack que a liga ao Angular |

## 📌 Resumo do curso

| Etapa | Ideia central | Ferramentas-chave |
| --- | --- | --- |
| 1. Lógica | pensar em algoritmos antes da linguagem | Portugol, fluxograma, vetores, funções, SQL, Git |
| 2. Web e HTML | estrutura e significado do conteúdo | HTTP, DNS, tags semânticas, formulários, SEO |
| 3. CSS | aparência e layout | cascata, box model, Flexbox, Grid, media queries, Sass |
| 4. JavaScript | comportamento da página | classes, módulos, DOM, eventos, `fetch` |
| 5. Angular | aplicação de página única | componentes, rotas, services, HttpClient |
| 6. Java | back-end orientado a objetos | classes, coleções, exceções, Spring Boot, CORS |

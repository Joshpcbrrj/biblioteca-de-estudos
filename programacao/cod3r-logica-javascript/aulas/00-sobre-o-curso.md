# Sobre o curso

> **🗺️ Sobre o curso:** lógica de programação do zero, usando JavaScript como linguagem. Você aprende a pensar em algoritmos, guardar e transformar dados, tomar decisões, repetir tarefas, organizar o código em funções e trabalhar com listas (arrays) e objetos. Cada tema tem uma aula e uma página de desafios resolvidos.

> **Como estudar:** siga as seções na ordem. Em cada aula, leia o quadro "Nesta aula", digite os exemplos e só então abra os desafios: tente resolver antes de abrir a resposta (**Ver resposta**). Para revisar, leia apenas os quadros **📌 Resumo** do fim de cada página.

> **🔖 Legenda dos quadros:** 🗺️ visão geral da aula · ✨ página nova, criada para cobrir um tópico que faltava · 💡 dica · ⚠️ cuidado · ✅ boa prática · 📌 resumo para revisão.

## Seções

| Seção | O que cobre |
| --- | --- |
| Comece aqui | O que é um algoritmo, teste de mesa e o ambiente para rodar JavaScript (Node.js e VS Code) |
| 1. Dados | Variáveis, tipos, conversões e os métodos mais usados de textos e números |
| 2. Operadores | Operadores aritméticos, de atribuição, relacionais, lógicos e ternário |
| 3. Estruturas de controle | Decidir com `if`/`else` e `switch`; repetir com `for`, `while` e `do...while` |
| 4. Funções | Funções, parâmetros, retorno, arrow functions, callbacks, closures e depuração de erros |
| 5. Arrays | Listas: acessar, percorrer e transformar com `map`, `filter`, `reduce`, `find` e `sort` |
| 6. Objetos | Modelar dados com objetos, métodos e classes |
| 7. Prática final | Padrões clássicos de algoritmos e uma lista final para juntar tudo |

## 📌 Resumo do curso

| Seção | Ao final você consegue… |
| --- | --- |
| Comece aqui | explicar o que é um algoritmo, fazer teste de mesa e rodar JavaScript com Node.js |
| 1. Dados | declarar variáveis, reconhecer tipos, converter valores e manipular textos e números |
| 2. Operadores | montar contas e condições com operadores aritméticos, relacionais e lógicos |
| 3. Estruturas de controle | decidir com `if`/`switch` e repetir com `for`/`while` |
| 4. Funções | criar funções reutilizáveis, usar callbacks e closures, ler erros e depurar |
| 5. Arrays | guardar listas e processá-las com `map`, `filter`, `reduce`, `find` e `sort` |
| 6. Objetos | modelar dados com objetos e classes |
| 7. Prática final | aplicar os padrões clássicos (contador, acumulador, maior/menor, busca, ordenação) |

## 📌 Resumo do curso

| Seção | Ideia central | Comandos-chave no Portugol |
| --- | --- | --- |
| Fundamentos | Algoritmo é um passo a passo ordenado, finito e sem ambiguidade | `programa { funcao inicio() { } }` |
| Variáveis e operadores | Dados têm tipo; expressões seguem a ordem de precedência | `inteiro`, `real`, `cadeia`, `logico`, `const`, `leia`, `escreva` |
| Decisão | O programa escolhe um caminho conforme uma condição | `se`, `senao se`, `senao`, `escolha`/`caso`, `inclua biblioteca` |
| Repetição | Repetir enquanto uma condição vale ou um número fixo de vezes | `enquanto`, `para`, `faca { } enquanto ()`, `pare`, `+=` |
| Estruturas de dados | Vários valores sob um nome, acessados por índice a partir de 0 | `vetor[i]`, `matriz[l][c]`, troca com `aux` |
| Sub-rotinas | Dividir o programa em partes reutilizáveis | `funcao tipo nome(params)`, `retorne`, `&` (referência) |

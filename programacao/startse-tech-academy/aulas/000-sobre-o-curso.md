# Sobre o curso

> 🎯 Formação de programação da **StartSe**, do zero ao desenvolvimento web completo: como o computador e a web funcionam → lógica → HTML e CSS → Git → JavaScript no navegador → orientação a objetos → Node.js no servidor → bancos de dados com SQL.

Cada aula segue o mesmo roteiro: **Nesta aula** → **De onde paramos** → conteúdo com exemplos e diagramas → **Exercício** (resposta recolhida em *Ver resposta*) → **Revisão rápida** → **Próximo passo** → **Resumo**.

**Legenda dos quadros:** 🗺️ o que a aula cobre · 💡 dica · ⚠️ correção ou cuidado · 🧠 revisão rápida · ➡️ próximo passo · 📌 resumo

## 📌 Resumo do curso

| Módulo | Ideia central | Chave |
| --- | --- | --- |
| I | o computador, o SO, o terminal e a web | cliente, servidor, HTTP |
| II | linguagens e lógica | compilado × interpretado, algoritmo |
| III | HTML: a estrutura | tags, tabelas, formulários, `alt` |
| IV | CSS: a aparência | seletores, cascata, box model |
| V | layout responsivo | media queries, Flexbox, Grid |
| VI | Git e GitHub | commit, branch, merge, pull request |
| VII | JavaScript no navegador | funções, arrays, DOM, `fetch` |
| VIII | semântica e frameworks | `header`, `main`, Bootstrap |
| IX | orientação a objetos | classe, herança, encapsulamento |
| X | Node.js e APIs | event loop, async/await, Express |
| XI | bancos de dados | tabelas, JOIN, índices, transações |

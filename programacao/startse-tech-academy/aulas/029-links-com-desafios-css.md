# Links com desafios CSS

> 🗺️ **Nesta lista:** jogos e desafios on-line para fixar seletores, Flexbox e Grid praticando.

## De onde paramos

Você acabou de ver seletores, pseudo-classes e pseudo-elementos. A melhor forma de fixar é praticar. Sugestão de ordem: seletores agora, Flexbox e Grid quando chegar ao módulo V, e os desafios livres no fim.

## Exercícios gerais

Exercícios curtos do W3Schools, organizados por tema:

🔗 [W3Schools CSS Exercise](https://www.w3schools.com/css/exercise.asp?filename=exercise_pseudo_classes4)

## Seletores

**CSS Diner**: selecione pratos e comidas numa mesa usando seletores, do básico (`plate`) ao avançado (`:nth-of-type`, `~`, `+`).

🔗 [CSS Diner](https://flukeout.github.io/)

## Flexbox (módulo V)

**Flexbox Froggy**: leve os sapos até as vitórias-régias usando `justify-content`, `align-items` e companhia. Tem versão em português.

🔗 [Flexbox Froggy](https://flexboxfroggy.com/#pt-br)

**Flexbox Defense**: um *tower defense* em que você posiciona as torres com Flexbox.

🔗 [http://www.flexboxdefense.com/](http://www.flexboxdefense.com/)

**Flexbox Zombies**: um curso em forma de jogo, com história.

🔗 [https://mastery.games/flexboxzombies/](https://mastery.games/flexboxzombies/)

## Grid (módulo V)

**Grid Garden**: regue a horta usando `grid-column`, `grid-row` e `grid-template`.

🔗 [https://cssgridgarden.com/](https://cssgridgarden.com/)

## Desafios livres

**CSS Battle**: reproduza uma imagem só com HTML e CSS, com o menor código possível.

🔗 [CSSBattle](https://cssbattle.dev/)

**100 Days CSS**: um desafio de design por dia, durante 100 dias.

🔗 [100 Days CSS Challenge](https://100dayscss.com/)

## Como aproveitar melhor

| Jogo | Meta | O que pratica |
| --- | --- | --- |
| CSS Diner | os 32 níveis | seletores e combinadores |
| Flexbox Froggy | os 24 níveis | eixos e alinhamento do Flexbox |
| Grid Garden | os 28 níveis | linhas e áreas do Grid |
| CSS Battle | 1 desafio por semana | tudo, com código enxuto |

Anote os seletores e propriedades que você não conhecia: eles viram uma colinha pessoal para os projetos.

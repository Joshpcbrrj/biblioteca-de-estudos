Aula 3 - SELECT
SELECT escolhe colunas. SELECT * pega tudo. WHERE filtra linhas, ex: WHERE idade > 18.
ORDER BY ordena, DESC é decrescente. LIMIT limita quantas linhas voltam.
JOIN junta tabelas pela chave. INNER JOIN só o que bate dos dois lados, LEFT JOIN pega tudo da esquerda.
GROUP BY agrupa e usa COUNT, SUM, AVG. HAVING filtra depois de agrupar.
Cuidado: WHERE não funciona com COUNT, tem que ser HAVING.

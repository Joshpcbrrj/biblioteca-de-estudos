# Integrations

**English** | [Português](README.pt-BR.md)

Everything that is connected or installed separately from the skill. None of them is required: without them, the skill writes the book just the same and gives you a zip to download. With them, it publishes and finds materials on its own.

## What each one is for

| Integration | What it is for | When the skill uses it | Guide |
| --- | --- | --- | --- |
| **GitHub** | Keep the books in your repository, save progress and publish | start (checkpoints) and end (publishing) | to be written |
| **Notion** | Read a material of yours to improve; create the book copy for your notes | Improve mode and the end | to be written |
| **Google Drive** | Find your books, PDFs and documents to use as sources | when you have materials to use | to be written |
| **Docling** | Convert PDF, DOCX, PPTX and other documents to text, keeping tables and structure | when you send documents | [docling.md](docling.md) |
| **GitHub Pages** | Publish the searchable website with every book | after the first publication | to be written |

## Where each one works

| Integration | Claude desktop app | Claude in the browser | Claude Code | Free plan |

| Notion (connector) | yes | yes | yes (MCP) | to be checked |

Items marked "to be checked" will be tested in phase 3 of the rebuild before they become rules.
